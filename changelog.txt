Version 8.0.0 (Update for Starsector 0.98.5a)

* All Silly MagicBounties are now enabled by default
  - "enableAdversarySillyBounties" setting now defaults to "true" (previously defaulted to "false")
* Added three new MagicBounties
  - Each bounty is available upon completing one of these bounty pairs: Hegemony/Luddic Church, Persean League/Sindrian Diktat, or Pirates/Luddic Path
* Changes to "An Even More Troublesome Mercenary" MagicBounty:
  - No longer considered a Silly bounty
  - Modified to closely match the three newly-added MagicBounties
  - Now requires completing the Tri-Tachyon/Independent bounty pair (previously only needed the Tri-Tachyon bounty)
  - Added Afflictor (P) ships to the bounty fleet
  - Increased credit reward
* Added one Silly MagicBounty, available after completing "Overwhelming Power"
* Added three super-ultra-difficult Silly MagicBounties, each requiring their respective ultra-difficult MagicBounty to be defeated first
  - Failure is almost always expected...
* Added 7 new MagicAchievements (4 visible, 3 hidden)
* Changes to "Omega Alpha Strike" Silly MagicBounty:
  - Revamped Remnant ship variants to no longer use Omega weapons
  - Tesseract variant now uses Omega weapons (from using ballistic PD loadout)
  - No longer requires accepting the vanilla Remnant+ bounty to be made available
  - Now requires defeating any of the starting Silly MagicBounties (those that only require level 15 or above) before being made available
  - Now awards the Scintilla blueprint upon completion
* Changes to Ziggurat Silly MagicBounty:
  - Changed the bounty name (previously was "The Alpha and the Omega")
  - No longer requires accepting the vanilla Remnant+ bounty to be made available
  - Now requires defeating all 4 paired MagicBounties (in addition to defeating the vanilla Ziggurat) before being made available
  - Doubled the credit reward for destroying the ship
* Other changes to MagicBounties:
  - Adjusted many bounty ship variants to account for 0.98.5a balance changes
  - Adjusted several bounty/officer skillsets to account for changes to bounty ship variants
  - Adjusted ship compositions for non-Silly bounties to account for officer number changes
  - Adjusted bounty faction spawn requirements, with most bounties now showing up in the bounty board if near a player market
  - Adjusted bounty rewards
  - "Overwhelming Power" now awards the Lumen blueprint upon completion
  - Modified Second-in-Command XO skills to account for v2.0.0 changes
  - All bounty variants now have s-modded built-ins (e.g., LG variants having s-modded Solar Shielding)
  - All support ships in station bounties now have officers commanding them
  - Fixed issue with vanilla variants being globally modified upon accepting "A Paradoxical Event"
* Changed Adversary market scoring to prioritize markets with higher ship quality and fleet size multiplier
  - This affects the spawn location of the Adversary system defense fleet and crisis fleets
* Added Ship Mastery System support for the Adversary faction (will have same mastery difficulty as mercenaries)
* Added "IndEvo_RuinsAlways" tag to Customizable Star Systems planets with Ind.Evo ruins to ensure they do not get removed
* Optimal system placement now uses market center of mass to calculate the closest constellation (previously used Core World centroid point)

Version 7.0.0 (Update for Starsector 0.98a)

* Compiled to Java 17
* Added Anubis to Adversary faction
* Removed dependency on Customizable Star Systems
  - The Optimal system generation is now built into the Adversary mod
  - The system now automatically supports Unknown Skies conditions and Industrial.Evolution industries
  - The system can spawn mid-game if it does not already exist
  - The one in the customStarSystems.json will be disabled by default
  - Added "enableAdversaryOptimal", "enableAdversaryUSOptimal", and "enableAdversaryIndEvoOptimal" settings to settings.json and LunaSettings
* Optimal Barren planet no longer has a Planetary Shield; its Heavy Batteries have been improved to partially compensate
* Fixed "enableAdversarySCSupport" option wrongly using the "enableAdversarySillyBounties" value if LunaLib was enabled
* Replaced Crew Training with Hull Restoration for Adversary commander skills
* Changes to specialized Adversary doctrines:
  - Now prioritizes the Hermes, Dram, and Mercury over the larger logistic ships to further bolster auto-resolve strength
  - Now also prioritizes non-primary ship types (e.g., Low Tech Carrier doctrine now also prioritizes Grendels and Vanguards)
* "enableAdversaryPersonalFleet" and related settings renamed to "enableAdversarySDF"
* Sword of Destruction fleet now made more difficult
* Now uses ColonyCrisisSetupListener to add the Adversary Colony Crisis
* Adversary CC attack changes:
  - Spawned fleets now focus on using more ships instead of higher-quality ships
  - Smaller attack fleets now favor using smaller ship classes over larger ones
  - Reduced reputation gain for defeating the attack
  - The enraged version is now much, much harder
* Modified some MagicBounty variants to account for 0.98a balance changes
* Nexerelin change: Adversary faction no longer has the "Neutralist" trait
